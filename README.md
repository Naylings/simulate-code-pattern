# Input Pattern Study

Situs statis untuk membandingkan implementasi input game menggunakan Command Pattern dan `if/else` langsung.

- Tugas A, Command Pattern: `/A/`
- Tugas B, tanpa pattern: `/B/`

Bagikan tautan tugas yang sesuai melalui Google Form. Peserta mengenali tugasnya dari label besar `INI ADALAH TUGAS A` atau `INI ADALAH TUGAS B`; situs tidak mengirim atau menyimpan data Google Form.

## Menjalankan lokal

Jalankan `python -m http.server 8000`, lalu buka `http://localhost:8000/`, `http://localhost:8000/A/`, atau `http://localhost:8000/B/`.

## Deploy GitHub Pages

Di GitHub, buka Settings > Pages, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`. URL bersifat peka huruf besar-kecil: gunakan `/A/` dan `/B/`.
